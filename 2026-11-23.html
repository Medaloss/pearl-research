06 — FP8 avance à 71 commits, OpenRouter affiche deux modèles

La PR #311 reste ouverte et passe de 68 à 71 commits depuis le relevé de dimanche. Cette progression du code proposé ne signifie pas que le changement est fusionné ou activé sur le réseau.

Consulté le 23 novembre 2026, vers 07 h 46–07 h 47, heure de Paris · GitHub officiel · PR #311

Les trois ajouts datés du 22 novembre portent, d’après leurs intitulés, sur le renommage de paramètres de tests, le déplacement de la préparation CPU B du C++ vers Rust et une correction de liaison de bibliothèque sous Windows. Ils documentent un travail d’intégration et de maintenance ; aucun gain chiffré de performance n’en est déduit ici.

Consulté le 23 novembre 2026, vers 07 h 50, heure de Paris · GitHub officiel · trois commits du 22 novembre

Le PIP-0003 porte toujours le statut Draft et la dernière release publiée reste v1.5.7. La proposition, la revue du code, la diffusion d’une version et son activation sont des étapes distinctes à documenter séparément.

Consulté le 23 novembre 2026, vers 07 h 46–07 h 49, heure de Paris · GitHub officiel · PIP-0003

Consulté le 23 novembre 2026, vers 07 h 46–07 h 49, heure de Paris · GitHub officiel · dernière release

Les trois éléments à surveiller en priorité

La réaction près de 2,11 $. Une progression accompagnée de volumes comparables sur la même paire donnerait plus de poids au rebond. Un rejet inviterait à observer la bande de 1,89–1,91 $.

La reprise de Wall Street. Les actions américaines rouvrent après une forte baisse vendredi, avant une semaine raccourcie par Thanksgiving. La réaction de PEARL devra être observée, sans supposer de corrélation automatique.

La suite des développements publics. Le code proposé et le catalogue d’inférence évoluent. Les prochaines confirmations attendues concernent les statuts de revue, les versions et des mesures d’usage comparables.

Le regard d’ensemble

Le rebond du week-end se prolonge jusqu’au relevé de lundi. L’encours des perpétuels remonte et le financement devient positif, tandis que le volume agrégé demeure plus faible. La progression de la PR FP8 et l’élargissement du catalogue sont vérifiables ; leur impact économique et leur lien avec le prix restent à établir.
